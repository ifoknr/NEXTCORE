# Notes for Claude sessions on this repository

## Release notes: Arabic and English
Every release's notes are written in both languages. `.github/release-notes.md`, the GitHub release body for the next release, holds:

1. the Arabic part (Gulf dialect, short bullets);
2. a line `**English**`;
3. the same in English.

Write it for each release; the Arabic part stays first, as it is now.

## Commits and pull requests

commit messages or pull request descriptions.
